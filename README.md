# 🎬 OTT Content & Subscriber Engagement Analytics

An end-to-end data analytics and business intelligence project analyzing subscription video-on-demand (SVOD) streaming telemetry, user retention dynamics, content performance, and personalization lift.

---

## 📌 Executive Summary
In the hyper-competitive OTT streaming landscape, retaining subscribers and optimizing content acquisition budgets are paramount. This project simulates and analyzes a platform dataset comprising user demographics, session telemetry, and subscription tiers to answer four core business questions:
1. **Subscriber Retention:** How does engagement decay over a 30-day user lifecycle?
2. **Content Strategy:** Which genres drive initial reach versus deep completion?
3. **Personalization Impact:** What is the quantitative lift generated by algorithmic recommendations?
4. **Monetization & Tiers:** How do ad-supported, standard, and premium tiers differ in engagement depth?
